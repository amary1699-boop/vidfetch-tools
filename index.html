Frequently Asked Questions

Common questions about VidFetch Tools.

What YouTube URLs are supported?

The analyzer supports standard YouTube watch links, youtu.be links, Shorts, Embed and Live URLs.

Can VidFetch convert an uploaded video?

Yes. The connected backend can process an uploaded file and return an actual MP4 or M4A file, subject to the backend's supported input limits and formats.

What is the maximum upload size?

The current conversion workflow is designed around files below 100 MB and supported processing limits.

Does the converter create MP3?

No. The current Cloudflare Media Transformations workflow used by VidFetch produces M4A/AAC for audio. MP3 requires a separate compatible conversion service.

Can I enter a YouTube URL and directly download its MP4?

The current backend does not fetch arbitrary YouTube media from a URL. The actual converter works with an uploaded file. Use only content you are authorized to download or process.

Are file sizes real?

Yes. The converted file size shown by the website comes from the actual returned file rather than a fabricated estimate.

Is the website mobile friendly?

Yes. The interface is responsive for desktop, tablet and mobile screens.
